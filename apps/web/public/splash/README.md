# iOS Splash Screens

This directory contains iOS splash screen images for PWA installation.

## Required Splash Screens

The following splash screens are referenced in `index.html`:

- `apple-splash-1290-2796.png` - iPhone 14 Pro Max / 15 Pro Max / Plus (430x932 @3x)
- `apple-splash-1179-2556.png` - iPhone 14 Pro / 15 Pro (393x852 @3x)
- `apple-splash-1170-2532.png` - iPhone 14 / 15 / 13 Pro / 12 Pro (390x844 @3x)
- `apple-splash-1284-2778.png` - iPhone 13 Pro Max / 12 Pro Max (428x926 @3x)
- `apple-splash-2048-2732.png` - iPad Pro 12.9" (1024x1366 @2x)
- `apple-splash-1668-2388.png` - iPad Pro 11" (834x1194 @2x)
- `apple-splash-1640-2360.png` - iPad Air / Mini (820x1180 @2x)

## Generating Splash Screens

You can generate these splash screens using:

1. **Online tools**: https://appsco.pe/developer/splash-screens
2. **PWA Builder**: https://www.pwabuilder.com/imageGenerator
3. **Design tools**: Export from Figma/Sketch at the required sizes

## Design Guidelines

- Use the app's background color (`#0f172a` for dark mode, `#ffffff` for light mode)
- Center the app logo
- Keep design minimal and fast-loading
- Match the theme color (`#10b981`)
